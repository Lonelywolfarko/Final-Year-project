# PCB Trace Routing System

A Python-based engineering project focused on PCB image processing and automated trace routing. The system aims to assist in analyzing PCB layouts and developing efficient routing solutions using computer vision techniques.

## Technologies Used
- Python
- OpenCV
- NumPy
- Image Processing

## Current Progress
- PCB image loading and preprocessing
- Noise reduction and edge detection
- Contour detection and filtering
- Identification of potential PCB features
- Processed image generation for visual inspection

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd Final-Year-project
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python main.py
```
